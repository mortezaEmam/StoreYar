# ADR-011 Frontend Architecture

- **Status:** Proposed
- **Context:** No SPA today (VERIFIED).
- **Decision:** Future UI = Nuxt 4 + Vue 3 + TS + Nuxt UI + Tailwind + typed API client. Defer build until API P0/P1 stable. Backend remains authority.
- **Alternatives:** Inertia; Livewire; expand Blade.
- **Migration impact:** Greenfield frontend; no dual UI maintenance.
