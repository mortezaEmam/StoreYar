# StoreYar — product surface complete

Admin can:

1. Register / login / reset password
2. Create organization and select business context
3. Manage categories and products (price, rename, activate, archive, category, filter)
4. Stock init/adjust
5. Orders draft → lines → confirm
6. Payments and shipments
7. Members invite / role / remove
8. Audit filter + CSV export
9. Dashboard counts

API is multi-tenant via `X-Business-Id` and membership checks.
